## 👋 关于我 / About Me

嗨，我是 **Shadow** —— 一名专注于开源情报（OSINT）与 AI 自动化的独立研究者。我热衷于构建能够「自动感知、自动分析、自动推送」的情报工具链，把海量公开信息转化为结构化、可行动的洞察。

- 🔭 **当前聚焦**：多源情报监控平台、自动化漏洞/公告推送、社交数据采集
- 🌱 **持续学习**：LLM 应用编排、知识图谱构建、MCP（Model Context Protocol）
- 💬 **可聊话题**：OSINT、Web 爬虫、Telegram 机器人、飞书/Lark 集成、AI Agent
